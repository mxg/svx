\section{Traits Classes}
\noindent\small\textit{File: \texttt{src/containers/traits.svh}}\par

The traits system provides per-type constants and static functions used by all parameterized containers and algorithms. Every traits class defines an \texttt{empty\_t} typedef, an \texttt{empty} constant, and static \texttt{equal()}, \texttt{compare()}, and \texttt{sort()} functions. The base class is \texttt{void\_traits}; scalar integer families derive from \texttt{base\_int\_traits}.
